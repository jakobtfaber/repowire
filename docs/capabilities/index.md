# Capabilities

What each Repowire feature does, where it is available, and what its limits are.

- [Dashboard](dashboard.md) — browser control surface and live session timeline.
- [Telegram](telegram.md) — phone-side routing, notifications, and attachments.
- [Slack](slack.md) — team chat control through Socket Mode.
- [Attachments](attachments.md) — local file upload and delivery paths.
- [Scheduling](scheduling.md) — one-shot and recurring mesh messages.
- [Jobs](jobs.md) — durable tracked work and recurring worker templates.
- [Spawning](spawning.md) — start or restart peers from configured runtime commands.
- [Orchestration](orchestration.md) — run a coordinator peer and route work through it.
- [Relay access](relay-access.md) — remote dashboard and cross-machine tunnel.
- [Memory](memory.md) — explicit mesh memory concepts and current CLI direction.
